CGI Calculator

Method: POST
Action: Update the action attribute to point to your CGI script
Data sent: num1, num2, operation

Sample CGI Script (Bash):

#!/bin/bash

echo "Content-Type: text/html"
echo ""

# Read POST data
if [ "$REQUEST_METHOD" = "POST" ]; then
    read -n $CONTENT_LENGTH POST_DATA
    
    # Parse the data (simple version)
    num1=$(echo "$POST_DATA" | sed 's/.*num1=\([^&]*\).*/\1/' | sed 's/%2E/./g')
    num2=$(echo "$POST_DATA" | sed 's/.*num2=\([^&]*\).*/\1/' | sed 's/%2E/./g')
    op=$(echo "$POST_DATA" | sed 's/.*operation=\([^&]*\).*/\1/')
    
    # URL decode operation
    case "$op" in
        "%2B") op="+" ;;
        "%2D") op="-" ;;
        "%2A") op="*" ;;
        "%2F") op="/" ;;
    esac
    
    # Calculate result
    case "$op" in
        "+") result=$(echo "$num1 + $num2" | bc) ;;
        "-") result=$(echo "$num1 - $num2" | bc) ;;
        "*") result=$(echo "$num1 * $num2" | bc) ;;
        "/") 
            if [ "$num2" != "0" ]; then
                result=$(echo "scale=2; $num1 / $num2" | bc)
            else
                result="Error: Division by zero"
            fi
            ;;
        *) result="Error: Invalid operation" ;;
    esac
    
    # Output HTML
    echo "<html><body>"
    echo "<h1>Calculator Result</h1>"
    echo "<p>$num1 $op $num2 = <strong>$result</strong></p>"
    echo "<a href='javascript:history.back()'>← Back to Calculator</a>"
    echo "</body></html>"
else
    echo "<html><body><h1>Error: Method not allowed</h1></body></html>"
fi

Setup Instructions:

  1. Save the script above as calculator.cgi in your web server's CGI directory
  2. Make it executable: chmod +x calculator.cgi
  3. Update the form action to match your CGI path
  4. Install bc calculator if not present: apt-get install bc
